# Contributing

Thanks for your interest in improving the Avocado OS MCP Server.

## Development

See the **Development** section of the [README](./README.md) for setup, build,
and testing instructions (`npm run build`, `npm run checks`, and testing against
a real MCP client).

Before opening a pull request:

- Run `npm run checks` (Prettier + TypeScript, including the test sources) and `npm test`, and make sure both pass.
- Keep changes focused and describe the behavior change in the PR.
